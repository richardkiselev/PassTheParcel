Make An App

Making an app for ParcelOS is simple! Simply code your app in an HTML file (using script and style tags). Send it over to Peanut in the Hack Club Slack, and it will be added in to the next version!

The website relies on iframes to generate windows. Other sources, such as URLs, can also work, but HTML files are the easiest to work with.

When you send over an app, please include an emoji to be used as the icon.
